# AI ChatNavigator 1.0.3

Version 1.0.3 fixes outline updates, message matching, and navigation cancellation for ChatGPT, Claude, and Gemini. Chat processing stays in your browser. The extension uses vanilla JavaScript and requests only the `storage` permission for sidebar preferences.

## Changes

1. **Stable outline updates.** Streamed replies update only changed entries, preserving keyboard focus and the sidebar's scroll position. The count reflects currently loaded prompts, without implying that the entire conversation is available.
2. **Cancellable navigation.** A click jumps immediately with at most one short position correction. Scrolling, touch input, scroll keys, another click, closing the sidebar, or switching chats cancels pending navigation.
3. **Safer message matching.** The extension checks live message nodes and IDs. If an edited, removed, or ambiguous prompt cannot be resolved safely, it shows a notice instead of selecting a target by repeated text or array position.
4. **Recovery and status feedback.** Loading, empty-chat, and error states include clearer messages and a Retry action. Observers can reconnect to replaced conversation containers. The popup distinguishes supported, loading, and unsupported pages.
5. **Keyboard access and privacy.** Outline entries and the sidebar opener are buttons with basic Tab/Enter support. Animations respect reduced-motion preferences, and extension debug logs omit conversation text.

## Install or update

1. Download `AI-ChatNavigator-v1.0.3-chrome.zip` from the [GitHub release](https://github.com/kamiimeteor/AI-ChatNavigator/releases/tag/v1.0.3) and extract it.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Choose **Load unpacked** and select the extracted folder containing `manifest.json`. If you already load this same folder, reload that extension entry after updating its files.
4. Refresh existing chat tabs to load the updated content scripts.

You can also install from the [Chrome Web Store](https://chromewebstore.google.com/detail/ai-chatnavigator/illmkheigijhoimkdghiaanedpinibmc?authuser=0&hl=en). Publishing this GitHub release does not establish Chrome Web Store approval or availability of the same version.

## Scope and limitations

The outline covers prompts currently loaded on the page. It does not fetch or archive unloaded history. It changes as the site loads or removes messages.

Support follows the adapters' ordinary-chat route rules. Project-specific, custom assistant, shared, and agent/work pages outside those rules are not supported. Site DOM changes can require adapter updates.

Search, bookmarks, reading-position restoration across conversations, resizable panels, and Chrome's native Side Panel are not included in this version.
