# AI ChatNavigator 1.0.4

Version 1.0.4 fixes disappearing ChatGPT outline entries, loads earlier prompts after opening or refreshing a conversation, and keeps the active entry aligned with the prompt and answer you are reading.

## Changes

1. **Keep observed ChatGPT prompts in the outline.** Previously read prompts remain in page memory while the same conversation, root container, unique message ID, and original placeholder survive. Unknown placeholders are not assumed to be user prompts. The sidebar shows `indexed prompts` and marks retained messages as `off-screen`.
2. **Load earlier prompts on opening or refresh.** The extension scrolls through unread placeholders already present on the page, then restores the original message and reading offset. A pass is limited to 15 seconds or 150 placeholders, with up to 1 second of waiting per placeholder. Scroll, touch, click, type, switch conversations, or hide the tab to cancel. Cancellation leaves the page under your control. If loading ends early, **Load remaining prompts** lets you continue.
3. **Navigate to off-screen messages.** Clicking an indexed prompt immediately scrolls to its placeholder, then checks up to 20 times at requested 40-millisecond intervals for the text to return. Navigation allows at most one position correction and stops on user input or a route change. Busy browsers may run timers later. Edits, deleted or replaced nodes, and ambiguous IDs invalidate stale targets.
4. **Track the prompt being read.** Active-entry tracking uses the reading position near the top of the scroll container and keeps a prompt active while you read its answer. This fixes the second entry taking the indicator after a jump to the first prompt in a large window. Scroll updates are grouped by animation frame.
5. **Show a lighter jump indicator.** A 2px violet outline follows the message bubble at 50% opacity: `#8B5CF6` in light mode and `#C4B5FD` in dark mode. It preserves the message background, stays for 1.5 seconds, and fades over 0.2 seconds. Reduced-motion mode removes it after 1.5 seconds without fading. Scrolling the conversation, selecting another prompt, closing the sidebar, or switching chats removes it early; scrolling the outline itself does not.

## Install or update

1. Download `AI-ChatNavigator-v1.0.4-chrome.zip` from the [v1.0.4 release](https://github.com/kamiimeteor/AI-ChatNavigator/releases/tag/v1.0.4) and extract it.
2. Open `chrome://extensions` and enable **Developer mode**. Disable other AI ChatNavigator installations to avoid duplicate sidebars.
3. Choose **Load unpacked** and select the extracted folder containing `manifest.json`. If you already load that same folder, reload its extension entry after updating the files.
4. Refresh existing chat tabs. On ChatGPT, allow automatic loading to finish, then click the first prompt to check navigation and the active indicator.

This package is available on GitHub. This release does not submit or update the [Chrome Web Store listing](https://chromewebstore.google.com/detail/ai-chatnavigator/illmkheigijhoimkdghiaanedpinibmc?authuser=0&hl=en).

## Scope and limitations

ChatGPT indexing lasts only for the current page and conversation. It does not persist prompt text across reloads. Automatic loading can briefly move the page, and restores the saved reading position only if you have not taken over. User input, loading limits, or history without page placeholders can leave the outline incomplete. The extension does not call private ChatGPT APIs or guarantee access to the entire server-side history.

Claude and Gemini still list currently loaded prompts; their message extraction is unchanged. All platforms still depend on their adapter route rules and page structure. Project-specific, custom assistant, shared, and agent/work pages outside those rules are not supported.

Search, bookmarks, reading-position restoration across conversations, resizable panels, and Chrome's native Side Panel are not included.
